# emls-extractor
Экспортер вложений из emls файлов. 

Использование:   
<code>python extract_attachments.py <папка_с_eml> <папка_для_сохранения> [--flat] </code>  
| Параметр | Значение |
|--|--|
| <папка_с_eml> | Путь для рекурсивного взятия .eml файлов  |
| <папка_для_сохранения> | Куда сохранять вывод программы  |
| --flat | Не создавать подпапку на каждое письмо, всё в одну папку  |
